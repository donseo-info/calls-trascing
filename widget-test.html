Добавь UTM в URL чтобы проверить захват:
?key=КЛЮЧ&utm_source=yandex&utm_medium=cpc&utm_campaign=test&yclid=1234567890
Что проверить:
1. Клик «Показать» выдаёт номер из пула сайта (или fallback если пул пуст).
2. В админке → «Запросы» появилась новая сессия с UTM/landing_page.
3. Симуляция звонка (вебхук) на выданный номер → в «Звонках» матчинг + отправка в Метрику.
4. Без ключа / с неверным ключом виджет показывает fallback-номер из data-ct-phone.
